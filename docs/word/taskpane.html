Changedown for Word

Open this pane from Microsoft Word.

This page is the hosted task pane for the Word add-in. For the remote room flow, install the remote-only manifest with a shell command and no local package tooling.

curl -fsSL https://changedown.com/word/install-mac.sh | bash
irm https://changedown.com/word/install-windows.ps1 | iex
  1. Run the macOS or Windows command above.
  2. It downloads the remote-only manifest, registers it with Word, and opens a launcher document.
  3. Open the Changedown pane in Word and click the remote-room action to invite a hosted agent.
View on GitHub Remote-only manifest

Local MCP users can still use npx @changedown/cli@latest word start for the loopback bridge path.
